## Project Overview

**DictéeRadio** is an offline, privacy-first medical voice dictation prototype for radiology report writing.  
It runs 100% locally — no cloud, no internet required.

- **Language**: Python 3.11
- **ASR engine**: [Vosk](https://alphacephei.com/vosk/) with the French model `vosk-model-fr-0.22`
- **Audio capture**: PyAudio (PortAudio wrapper)
- **GUI**: Tkinter (built-in)
- **Stage duration**: 1 month internship prototype

## Architecture & Data Flow

```
Microphone (PyAudio)
     │  PCM chunks — 16 kHz, int16, mono, 4000 frames/chunk
     ▼
KaldiRecognizer (Vosk)
     │  JSON: {"partial": "..."} or {"text": "..."}
     ▼
format_text()   [semaine3/text_formatter.py]
  ├── apply_phonetic_corrections()   ← fixes Vosk mishearings
  ├── apply_punctuation_commands()   ← "virgule" → ","
  ├── apply_unit_shortcuts()         ← "millimètres" → "mm"
  ├── fix_spacing()                  ← removes spurious spaces
  └── capitalize_sentences()         ← first char after . ! ?
     │
     ▼
Tkinter Text widget
  └── highlight_medical_terms()      ← blue tag on known medical words
```

## Key Modules

### `main.py`
Single CLI entry point. Parses `--mode` (`gui` | `terminal`), `--model`, `--device`, `--list-devices`.  
Runs pre-launch checks (`check_vosk_available`, `check_pyaudio_available`, `check_model_exists`) before delegating to `launch_gui()` or `launch_terminal()`.

```
python main.py                            # GUI (default)
python main.py --mode terminal            # terminal-only
python main.py --list-devices             # list mics and exit
python main.py --model /path/to/model     # custom model path
```

---

### `semaine1/hello_vocal.py`
- **`stream_microphone(model_path, device_index)`** — opens PyAudio stream with a callback that pushes `bytes` into a `queue.Queue`. A loop reads the queue and feeds chunks to `KaldiRecognizer.AcceptWaveform()`. Prints partial (in-place `\r`) and final (`\n`) results.
- Audio constants: `SAMPLE_RATE=16000`, `CHUNK_SIZE=4000`, `FORMAT=paInt16`, `CHANNELS=1`.

---

### `semaine2/medical_vocab.py`

**`MEDICAL_VOCABULARY`** — `dict[str, list[str]]` with 7 categories (~130 terms total):

| Category key           | Examples |
|------------------------|---------|
| `imagerie_generale`    | IRM, échographie, scanner, tomodensitométrie |
| `anatomie`             | parenchyme, cortex, péricarde, mésentère |
| `thorax`               | pneumothorax, atélectasie, consolidation, pleurésie |
| `abdomen`              | cholécystite, ascite, hépatomégalie, stéatose |
| `neuro_cranien`        | ischémie, hématome sous-dural, hémorragie méningée |
| `os_articulations`     | fracture, luxation, ostéoporose, arthrose |
| `terminologie_descriptive` | hypodense, hyperdense, spiculé, hétérogène |
| `compte_rendu`         | conclusion, technique d'examen, aspect stable |

**`PHONETIC_CORRECTIONS`** — `dict[str, str]` mapping common ASR errors to correct terms:  
e.g. `"irm"→"IRM"`, `"i r m"→"IRM"`, `"paranchyme"→"parenchyme"`, `"pneumo thorax"→"pneumothorax"`.

**`build_vosk_vocab_file(output_path)`** — writes `data/vocab_medical.txt` (one lowercase word per line) for use with `KaldiRecognizer.SetGrammar()`.

**`apply_phonetic_corrections(text)`** — lowercase replace loop over `PHONETIC_CORRECTIONS`.

### `semaine3/text_formatter.py`

**`PUNCTUATION_COMMANDS`** — spoken words mapped to symbols:

| Spoken word | Output |
|---|---|
| `virgule` | `,` |
| `point` | `.` |
| `deux points` | `:` |
| `point d'interrogation` | `?` |
| `nouveau paragraphe` | `\n\n` |
| `nouvelle ligne` | `\n` |
| `effacer dernier mot` | `__DELETE_LAST__` (special token) |
| `effacer tout` | `__CLEAR__` (special token) |

**`UNIT_SHORTCUTS`** — regex patterns for unit conversion:  
`millimètres?` → `mm`, `centimètres?` → `cm`, `kilogrammes?` → `kg`, etc.

**`format_text(raw, highlight=False)`** — the main pipeline:
1. `apply_phonetic_corrections()`
2. `apply_punctuation_commands()` (sorted longest-first to avoid partial matches)
3. `apply_unit_shortcuts()`
4. `fix_spacing()` (no space before `,;:.!?`, normalize multiples)
5. `capitalize_sentences()` (regex after `.!?` or start)
6. optionally `highlight_medical_terms()` (wraps in `[brackets]` for debug)

**`Transcription` dataclass** — accumulates `raw_segments: list[str]`, recomputes `final_text` via `format_text()` on each `append_segment()`. Supports `clear()` and `delete_last_word()`.

### `semaine4/app_tkinter.py` — `DicteeVocaleApp(tk.Tk)`

**Color palette** (`COLORS` dict):

| Key | Hex | Role |
|---|---|---|
| `bg` | `#1A1A2E` | dark navy background |
| `panel` | `#16213E` | slightly lighter panels |
| `accent` | `#0F3460` | dark medical blue |
| `highlight` | `#E94560` | vivid red for record button |
| `medical_term` | `#4FC3F7` | light blue for medical words |
| `partial` | `#FFB74D` | orange italic for partial text |

**Key methods**:
- `_load_model_async()` — loads Vosk model in a daemon thread; calls `SetGrammar()` with `vocab_medical.txt` if available; updates UI on completion via `self.after(0, ...)`.
- `_start_recording()` — opens PyAudio stream with callback that pushes audio to `audio_queue` AND computes RMS volume for `ttk.Progressbar`. Starts `_recognition_loop()` in a daemon thread.
- `_recognition_loop()` — reads `audio_queue` with `timeout=0.5`; on final result calls `format_text()` and schedules `_append_text()` via `self.after(0, ...)`.
- `_highlight_medical_terms()` — uses `txt_main.search()` in a loop to apply the `"medical"` tag (light blue) to all known terms.
- `_save_text()` — `filedialog.asksaveasfilename()` → `Path.write_text(encoding="utf-8")`.
- Thread safety: all Tkinter updates are dispatched via `self.after(0, callback)` from worker threads — never called directly.

### `utils/errors.py`

Custom exception hierarchy:
```
DicteeRadioError (base)
├── ModelNotFoundError
├── AudioDeviceError
└── DependencyError
```

Pre-launch check functions (each calls `sys.exit(1)` on failure):
- `check_vosk_available()` — tries `import vosk`
- `check_pyaudio_available()` — tries `import pyaudio` + checks for at least one input device
- `check_model_exists(model_path)` — verifies `am/final.mdl` and `conf/model.conf` exist
- `safe_open_stream(pa, rate, chunk, device_index)` — wraps `pa.open()` with clear `AudioDeviceError`
- `print_startup_banner()` — ASCII banner with ANSI colors

## Important Conventions

- **Thread safety**: Worker threads (audio callback, recognition loop, model loader) must **never** touch Tkinter widgets directly. Always use `self.after(0, callback)`.
- **Audio format**: Vosk requires exactly **16 kHz, 16-bit (int16), mono** PCM. Any deviation will produce garbage output.
- **Imports**: `semaine3` imports from `semaine2`; `semaine4` imports from `semaine3`. Always run from the project root (`python main.py`) so `sys.path` is set correctly.
- **Model path**: Default is `vosk-model-fr-0.22` (relative to CWD). Pass `--model` to override.
- **vocab_medical.txt**: Used as a grammar constraint (`KaldiRecognizer.SetGrammar()`). Regenerate after modifying `MEDICAL_VOCABULARY` by running `python semaine2/medical_vocab.py`.
- **Special tokens** `__DELETE_LAST__` and `__CLEAR__` returned by `apply_punctuation_commands()` are handled upstream in `DicteeVocaleApp` (not inside `format_text()`).
